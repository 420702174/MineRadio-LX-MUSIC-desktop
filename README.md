# MineRadio-LX-MUSIC-desktop
基于MineRadio二次开发（原项目地址：https://github.com/XxHuberrr/Mineradio）请支持原作者，增加支持LX音源播放，本地歌单等无需登录账号即可播放;还有啥功能自己看吧，懒得写了，主要就是适配LX Music自定义音源；在线的音源没有测试，因为我没有；本地的json文件没问题，搜索框旁边有LX的按钮（首先要打开DIY模式），支持批量导入；导入后直接搜索歌曲，不需要选择渠道，无论哪个渠道搜出来的，只要音源里面有的都能正常播放；
